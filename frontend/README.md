## Project Overview

### components/

The `components/` directory contains reusable React components organized into specific categories:

- **feedback/**: Components designed to provide feedback to the user.
  
- **input/**: Components for various form inputs including buttons, calendars, input fields, selection fields, and time fields.
  
- **layout/**: Components that define the overall appearance and structure of the application, including page styles and components.
  
- **pages/**: Components tied to diffrent pages representing subpages of the application, particularly focused on settings.

### hooks/

The `hooks/` directory houses custom React hooks that encapsulate specific logic for reuse throughout the application.

### pages/

The `pages/` directory contains main page components that compose the core user interface of the application. Each page represents a path within the application.

### types/

The `types/` directory defines types that are used within the application.

### utils/

The `utils/` directory includes utility functions that streamline common tasks such as handling cookies and making HTTPS requests with CSRF protection, enhancing the application's functionality and security. It also includes `mySWR`, a custom React hook that integrates SWR (React Hooks for data fetching) with Axios for managing asynchronous data fetching, updating, and caching while ensuring CSRF token inclusion for secure HTTPS requests.

### Other Files

- **index.css**: The main CSS file defining global styles for the application. Is generated by tailwind css.
  
- **main.tsx**: The entry point for the React application, responsible for rendering the main React component and mounting it to the DOM.


## Technologies Overview
- **React with TypeScript**: React is a JavaScript library for building user interfaces, enhanced with TypeScript for static typing, enabling developers to catch errors early and improve code quality.

- **Vite**: Vite is a fast front-end build tool optimized for modern JavaScript frameworks like React and TypeScript. It provides instant server start, fast hot module replacement (HMR), and optimized production builds.

- **Tailwind UI**: Tailwind UI offers a comprehensive set of pre-designed components and utility classes built with Tailwind CSS. It accelerates UI development by enabling rapid prototyping and styling without custom CSS, ensuring consistent design and facilitating maintenance and updates following best practices in web design and accessibility.

- **SWR (Stale-While-Revalidate)**: SWR is a React Hooks library tailored for efficient data fetching in your restaurant booking tool. It seamlessly integrates with TypeScript and implements caching strategies like "stale-while-revalidate". This ensures optimal performance by automatically caching data and updating it as needed. Utilize SWR's mutate function to seamlessly update data in the background without requiring a UI refresh, making it ideal for tasks such as adding or modifying bookings.

- **react-router-dom**: React Router serves as a critical library within our application, providing robust routing capabilities essential for managing navigation between different components and views seamlessly. By synchronizing the UI with the browser's URL, React Router enables a smooth user experience without the need for full page reloads.
